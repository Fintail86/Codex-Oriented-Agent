# COSIA v0.20 Plan: Review Inbox in Chat

## Summary

v0.20 adds a Review Inbox so pending memory and skill candidates can be inspected and handled from the shared chat REPL.

## Scope

- Add `src/runtime/review_inbox.ts`.
- Add `/review` commands to the shared REPL.
- Add read-only `cosia review`, `cosia review --memory`, and `cosia review --skill`.
- Keep existing detailed memory and skill candidate CLI commands.
- Do not add TUI/Ink.

## Principles

- Promote/discard actions are runtime commands, not natural language model responses.
- Review indexes are temporary display helpers.
- Stable id prefixes are preferred in action hints.
- Memory conflict gates and skill promotion confirmation rules stay intact.

## Validation

- `npm run typecheck`
- `npm test`
- `npm run build`
- `cosia policy check --repair`
