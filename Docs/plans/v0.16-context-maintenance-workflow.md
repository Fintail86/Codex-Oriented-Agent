# COSIA v0.16 Plan: Context Maintenance Workflow

## Summary

v0.16의 목표는 길어지는 `CONTEXT_MEMORY.md`를 안전하게 관리하는 것이다.

- 버전은 `0.16.0`.
- 자동 백그라운드 요약/삭제는 하지 않는다.
- 요약은 사용자가 명시적으로 실행할 때만 생성/저장한다.
- 컨텍스트 정리는 preview-first, `--yes` 적용 방식으로 한다.
- `CONTEXT_MEMORY.md` compact는 반드시 `## Run ...` block 단위로 처리한다.
- REPL에서도 y/n 중첩 입력 대신 CLI와 같은 `--yes` 명시 적용 방식을 사용한다.

## Key Changes

### Context Status

추가 명령:

```text
cosia session context status <session-id>
```

출력:

- `CONTEXT_MEMORY.md` chars
- run entry count
- warning/critical threshold 상태
- `SESSION_SUMMARY.md`가 기본 placeholder인지 여부
- archive된 entry 수
- 권장 다음 명령

### Session Summarize From Context

기존 명령 유지:

```text
cosia session summarize <session-id> --content "<summary>"
```

추가:

```text
cosia session summarize <session-id> --from-context --provider <provider>
cosia session summarize <session-id> --from-context --provider <provider> --yes
```

기본은 preview만 출력하고, `--yes`가 있을 때만 `SESSION_SUMMARY.md`를 갱신한다.

### Context Compact

추가 명령:

```text
cosia session context compact <session-id> --keep-last <n> --reason "<reason>"
cosia session context compact <session-id> --keep-last <n> --reason "<reason>" --yes
cosia session context compact <session-id> --keep-last <n> --reason "<reason>" --yes --allow-empty-summary
```

동작:

- `^## Run .+$` 정규식 기준으로 run block을 파싱한다.
- `# CONTEXT MEMORY` 헤더와 run entry 바깥 preamble은 보존한다.
- 최신 N개 run block만 `CONTEXT_MEMORY.md`에 남긴다.
- archive되는 run block은 원문 그대로 `CONTEXT_ARCHIVE.md`에 보존한다.
- 기본적으로 `SESSION_SUMMARY.md`가 placeholder 상태면 compact를 거부한다.

### Chat UX

REPL 명령 추가:

```text
/context status
/context compact --keep-last <n> --reason "<reason>"
/context compact --keep-last <n> --reason "<reason>" --yes
/summary show
/summary update <summary>
```

## Test Plan

- `session context status`가 chars, run count, summary 상태, warning/critical 상태를 출력한다.
- `session summarize --content` 기존 동작이 유지된다.
- `session summarize --from-context`는 preview만 출력하고 파일을 바꾸지 않는다.
- `session summarize --from-context --yes`는 `SESSION_SUMMARY.md`를 갱신한다.
- provider 실패 시 summary 파일은 변경되지 않는다.
- `context compact`는 preview만 출력하고 파일을 바꾸지 않는다.
- `context compact --yes`는 오래된 run blocks를 archive로 이동하고 최신 N개만 남긴다.
- compact는 `^## Run .+$` block 기준으로 동작하며 run 내부 내용을 쪼개지 않는다.
- `PROMPT_MANIFEST.jsonl`에 context health metadata가 기록된다.
- 기존 v0.15.1 tests 유지.
