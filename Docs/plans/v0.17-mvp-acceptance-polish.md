# COSIA v0.17 Plan: MVP Acceptance Polish

## Summary

v0.17의 목표는 새 기능 확장이 아니라 MVP 완료 판정 기준을 고정하는 것이다.

- 버전은 `0.17.0`.
- `mock`은 회귀 테스트용으로 명시하고, MVP 완료 기준에서는 제외한다.
- MVP acceptance는 `codex-cli` OAuth provider 기준으로 고정한다.
- OpenRouter/openai-compatible은 optional provider acceptance로 분리한다.
- 체크리스트는 사람이 그대로 따라 하기 쉬운 plain text/Markdown 중심으로 만든다.
- 새 콘솔 색상 dependency는 추가하지 않는다.

## Key Changes

- `MVP_ACCEPTANCE.md`를 tracked 문서로 추가한다.
- `cosia mvp checklist` 명령을 추가한다.
- checklist 출력은 `[ ]` 단계, command, expected outcome을 포함한다.
- README는 `codex-cli` 기준 MVP acceptance와 `mock`의 회귀 테스트 역할을 명확히 구분한다.
- 기존 OpenRouter 사용자 설정은 보존한다.

## Test Plan

- `cosia mvp checklist`가 plain text checklist를 출력한다.
- checklist 출력에서 `mock`이 MVP 완료 기준이 아님을 명시한다.
- `MVP_ACCEPTANCE.md`의 각 단계에 Expected Outcome이 있다.
- 기존 v0.16 tests 유지.

검증 명령:

```text
npm run typecheck
npm test
npm run build
cosia policy check --repair
```
