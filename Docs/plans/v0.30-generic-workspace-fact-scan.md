# COSIA v0.30 Plan: Generic Workspace Fact Scan

## Summary

v0.30 stabilizes `EnvironmentDiscovery` as a generic workspace fact layer. The scanner observes workspace structure and limited file shapes without inferring concrete tools, runners, commands, or capabilities.

## Key Decisions

- Facts are observations, not tool assumptions.
- Scan performs no shell, probe, or command execution.
- Exact names and shapes may classify fact kinds, but must not imply concrete tools or runners.
- `.git` is a hidden entry, not Git capability.
- `package.json` is a manifest-like file, not NPM capability.
- Every scan creates a new snapshot with `scanId`; repeated scans do not overwrite old facts.
- `legacy_v0.29` is a reserved scan id for legacy fact compatibility.
- Structured file parsing checks `stat.size` before reading/parsing.
- README-like summaries are deterministic, capped, redacted truncations with no LLM call.
- Paths, keys, summaries, and warning messages are redacted.
- Symlinks use `lstat`/`realpath`, visited realpath cycle detection, and workspace-boundary checks.
- Stable JSON is output-only; DB storage remains normal schema/JSON records.

## Public Interfaces

- `cosia capability scan [--request "<text>"] [--json]`
- `cosia capability facts [--latest] [--scan-id <id>] [--json]`
