# COSIA v0.27.3 Plan: Generalized Bundled Tool Catalog

## Summary

v0.27.3 generalizes bundled tool handling so Git and NPM tools are registered through a metadata-only ToolCatalog instead of being individually hardcoded across policy, config, prompt contracts, provider schemas, and agent defaults.

## Key Decisions

- Core runtime tools remain `read_file`, `write_file`, and `search_files`.
- Git and NPM are bundled extension tools, not Codex law.
- Runtime config may only toggle bundled tool `enabled`.
- ToolCatalog owns metadata only; executor input validation and policy decisions stay outside the catalog.
- `npm_test` and `npm_typecheck` use `project_check`, not `read_only`.
- Normal `loadAgent()` must not restore user-removed allowed tools.
- Provider schema can include registered model-exposed tool ids, while prompt contracts only show effective available tools for the current run.
- Runtime gate remains the final enforcement point for unavailable tool calls.
