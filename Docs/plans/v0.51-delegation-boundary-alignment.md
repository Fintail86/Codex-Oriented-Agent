# COSIA v0.51 Plan: Delegation Boundary Alignment

## Summary

v0.51의 목표는 새 Codex 법전 방향을 런타임 전체에 일관되게 반영하는 것이다.

핵심 원칙:

- 최종 사용자 승인은 Codex 자기개정과 시스템 레벨 경계 변경에만 요구한다.
- 일반 workspace-local 작업은 active Policy 아래에서 위임 가능하다.
- 기존 파일 수정은 그 자체로 시스템 레벨 변경이 아니다.
- Telegram/gateway 같은 외부 표면은 더 보수적으로 preview/apply를 유지한다.

## Key Changes

- 버전은 `0.51.0`.
- Codex delegation 변경분을 기준선으로 정리한다.
- `SystemBoundaryClassifier` 또는 동등한 runtime helper를 추가한다.
- Codex law, provider/connector authority, policy/security gate 완화, permission class 변경, workspace boundary 변경은 system-level로 분류한다.
- ordinary workspace-local file write는 delegated로 분류한다.
- agent behavior/style file update는 delegated이며 evidence를 기록한다.
- `cosia pending`은 shell approval, Codex amendment, gateway pending preview를 구분한다.

## Test Plan

- ordinary workspace-local existing file overwrite는 기본적으로 승인 없이 적용된다.
- Telegram forced overwrite preview 예외는 유지된다.
- `codex/*` protected law write는 amendment flow로만 연결된다.
- provider/connector authority 변경과 disabled permission 완화는 system-level로 분류된다.
- agent `STYLE.md` 변경은 일반 delegated write로 처리된다.

## Assumptions

- v0.51은 새 기능 추가가 아니라 approval boundary alignment다.
- system-level classifier는 rule 기반이며 LLM 판단에 맡기지 않는다.
