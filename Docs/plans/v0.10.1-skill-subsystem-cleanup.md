# COSIA v0.10.1 Plan: Skill Subsystem Structural Cleanup

## Summary

Split the large global skill toolbox implementation into focused modules without changing behavior.

Version: `0.10.1`.

## Key Changes

### Module Split

Keep `src/runtime/skill_manager.ts` as public facade.

Move internals under:

```text
src/runtime/skills/
  skill_text.ts
  skill_store.ts
  skill_candidates.ts
  skill_selector.ts
  skill_mirror.ts
  skill_migration.ts
  skill_formatters.ts
```

Responsibilities:

- `skill_text.ts`: pure text helpers.
- `skill_store.ts`: global skill md/json and agent manifest file access.
- `skill_candidates.ts`: SQLite candidate queue and promote/discard/export.
- `skill_selector.ts`: scoring, preference/weight bonus, tie-breakers, budget.
- `skill_mirror.ts`: global and agent `SKILLS.md` generation/check/repair.
- `skill_migration.ts`: legacy agent-local migration.
- `skill_formatters.ts`: readable CLI output.

### Dependency Direction

Avoid circular dependencies:

```text
skill_text
  -> skill_store
    -> skill_candidates / skill_selector / skill_mirror / skill_migration / skill_formatters
      -> skill_manager facade
```

Rules:

- `skill_text.ts` imports no skill subsystem modules.
- `skill_store.ts` imports only text helpers and common types.
- Leaf modules do not import `SkillManager`.
- `SkillManager` composes lower modules.

### Facade Construction

`SkillManager` creates submodules once in constructor and reuses them.

No DI framework or over-abstraction.

### Behavior Preservation

Do not change:

- CLI commands.
- DB schema.
- Metadata schema.
- Agent manifest schema.
- Skill selection behavior.
- Public exports such as formatters and scoring helpers.

Do not split `memory_manager.ts` or `cli.ts` in this version.

## Test Plan

- Existing v0.10 tests pass.
- Facade method names still work.
- Candidate promote still updates global md/json/mirror.
- `skill select --explain` results remain stable.
- Blocked skill behavior unchanged.
- Migration preview/apply unchanged.
- Global/agent skill check repair unchanged.

Validation:

```text

npm test
npm run build
node dist\src\bin.js policy check --repair
node dist\src\bin.js skill check --repair
node dist\src\bin.js skill check --agent architect-agent --repair
```
