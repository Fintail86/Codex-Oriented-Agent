# COSIA v0.40 Plan: Identity Surface Refactor

## Summary

v0.40의 목표는 COSIA의 공개 표면을 새 정체성에 맞추는 것이다.

핵심 문장:

```text
COSIA is a lightweight, provider-neutral agentic runtime guided by a user-amendable Codex.
```

이번 단계는 기능 추가가 아니라 정체성, 문구, 문서, CLI 설명 정렬이다.

## Key Changes

- 버전은 `0.40.0`.
- README 첫 문장과 CLI root description에서 MVP/clone 느낌을 줄인다.
- `Codex-Oriented`는 OpenAI Codex 제품 종속이 아니라 `codex/` 법전 중심이라는 점을 설명한다.
- Quick Start는 normal UX 중심으로 재정렬한다.
- capability/tool growth 명령은 advanced section으로 이동한다.
- `codex-cli`는 기본 provider가 아니라 명시적으로 추가 가능한 provider profile로 설명한다.
- historical MVP acceptance 표현은 historical/manual acceptance로 정리한다.

## Public UX

- Normal path: `init`, provider setup, `start/chat/run`, status/doctor, gateway connector, memory.
- Advanced path: capability/tool growth, candidate, active tool, blueprint, shell bridge.
- Debug/governance path: policy/config repair, command triggers, low-level ledgers.

## Test Plan

- `npm run typecheck`
- `npm test`
- `npm run build`
- `node dist/src/bin.js --help`
- `node dist/src/bin.js provider profile list`
- `node dist/src/bin.js config check`
- `node dist/src/bin.js policy check`

## Assumptions

- v0.40 does not change runtime behavior.
- Detailed refactor execution docs live under `Docs/refactors/`.
