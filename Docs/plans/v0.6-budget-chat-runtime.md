# COSIA v0.6 Plan: Budget + Chat Runtime

## Summary

Introduce prompt budget controls and make sessions usable as interactive chat/work units instead of one-shot runs.

Version: `0.6.0`.

## Key Changes

### Chat REPL

Add:

```text
cosia chat --session <session-id> [--provider <provider>]
```

Supported commands:

```text
/exit
/status
/memory refresh
```

Behavior:

- Normal input uses existing run loop.
- Durable source of truth is `CONTEXT_MEMORY.md`.
- In-process history array is cache/display only.
- Static prompt blocks load once at REPL start:
  - Codex files
  - agent files
  - session rules
- Dynamic blocks refresh per input:
  - `CONTEXT_MEMORY.md`
  - tool results
  - current request
- `REF_MEMORY.md` refreshes at REPL start, on `/memory refresh`, or after memory auto-promotion.

### Session Summary

Add:

```text
SESSION_SUMMARY.md
cosia session summarize <session-id> --content "<summary>"
```

v0.6 does not auto-summarize. On REPL exit, print a summary hint.

### Prompt Budget

Default:

```json
{
  "maxPromptChars": 60000,
  "refMemoryMaxItems": 8,
  "contextTailChars": 6000,
  "toolResultsMaxChars": 12000
}
```

Prompt priority:

1. `SECURITY.md`
2. `POLICY.md`
3. `RULES.md`
4. `SOUL.md`
5. `USER.md`
6. Agent files
7. `SESSION_RULES.md`
8. `SESSION_SUMMARY.md`
9. scored `REF_MEMORY.md`
10. `CONTEXT_MEMORY.md` tail
11. tool results
12. current request

Never truncate:

- `SECURITY.md`
- `POLICY.md`
- current request

### Prompt Manifest

Add per-session:

```text
PROMPT_MANIFEST.jsonl
```

Record:

- run id
- model step
- block char counts
- estimated tokens
- safety margin
- truncated/overflow flags

Do not store full prompt body.

### Provider Config Structure

Add policy-backed model config:

```json
{
  "model": {
    "defaultProvider": "codex-cli",
    "providers": {
      "codex-cli": {
        "enabled": true,
        "sandbox": "read-only"
      },
      "openai-compatible": {
        "enabled": false,
        "baseUrl": null,
        "model": null
      }
    }
  }
}
```

Only config structure is introduced; API provider is deferred.

## Test Plan

- Prompt budget records manifest metadata.
- Required blocks are not truncated.
- Chat appends to `CONTEXT_MEMORY.md`.
- REPL restart uses context tail, not in-memory array.
- `REF_MEMORY.md` refreshes at REPL start and on `/memory refresh`.
- `SESSION_SUMMARY.md` is included in prompt assembly.
- `/status` and `/exit` work.
- Static block cache is reused during REPL session.
- Existing run/memory/policy/promotion tests pass.

## Assumptions

- Character budget is accepted as a temporary approximation.
- Tokenizer is deferred.
- Automatic session summary is deferred.
- Provider API implementation is deferred.
