# COSIA v0.19.1 Plan: Shared Chat REPL Polish

## Summary

v0.19.1 polishes the UX Foundation by making `cosia start` and `cosia chat` use the same reusable chat REPL.

## Key Changes

- Add `src/runtime/repl.ts` with `runChatRepl()` and `/help`.
- Make `cosia chat` and `cosia start` both call `runChatRepl()`.
- Remove the simplified `runBasicStartChat` path.
- Keep `/exit` graceful by returning from the REPL instead of terminating the process.
- Show selected session, provider, assigned agent, and equivalent command before `start` enters chat.
- Block `start` chat entry when the selected provider is not ready.
- Add `No files changed.` to reset previews.

## Test Plan

- Verify `start --no-chat` prints the next command without entering chat.
- Verify `start` and `chat` share `/help`, `/status`, `/context`, `/summary`, `/skills`, `/memory refresh`, and `/exit`.
- Verify provider failure blocks chat entry with reason and hint.
- Verify `doctor reset --state` preview does not mutate files and says `No files changed.`
- Run `npm run typecheck`, `npm test`, `npm run build`, and `cosia policy check --repair`.

## Assumptions

- v0.19.1 is a polish/refactor version.
- No external UI dependency is introduced.
- TUI remains a v0.20 decision.
