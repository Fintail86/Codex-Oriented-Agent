# COSIA v0.23-v0.26 Plan: Remote Review UX, Gateway Reliability, Queue Governance, Command Packs

## Summary

v0.22로 Telegram Gateway MVP가 성공했으므로 다음 페이즈는 기능 확장보다 원격 사용성, 장시간 실행 안정성, review queue 관리성을 다듬는다.

우선순위:

1. v0.23: Telegram / Chat Review UX Polish
2. v0.24: Gateway Daemon Stability
3. v0.25: Review Queue Governance & Cleanup
4. v0.26: Command Language Packs + TUI Decision Checkpoint

## v0.23

- Telegram `/review` 출력을 모바일 친화 compact format으로 정리한다.
- Telegram callback button을 최소 도입한다.
- 버튼은 shortcut일 뿐 권한이 아니며 mutation은 preview + `/apply` 또는 `#적용`을 유지한다.
- preview freshness metadata를 저장하고 apply 시 target 상태, chat/session, TTL, conflict snapshot을 재검증한다.
- chat REPL과 Telegram review는 같은 ReviewInboxService와 id-prefix 기준을 사용한다.

## v0.24

- gateway process lock에 pid, lockId, workspacePath, gatewayId, command, startedAt, heartbeatAt을 기록한다.
- gateway loop가 heartbeat를 갱신한다.
- `cosia gateway status --json`을 추가한다.
- stale lock 판단은 PID뿐 아니라 workspacePath, gatewayId, heartbeat age, process presence를 함께 본다.
- `cosia gateway telegram unlock --stale-only`를 추가한다.
- `.cosia-gateway/telegram/log.jsonl`에 start/stop/failure/update 요약을 기록한다.
- `cosia doctor`에 gateway 진단을 포함한다.

## v0.25

- `cosia review stats`를 추가한다.
- `cosia review cleanup`을 추가한다.
- cleanup은 preview-first이며 `--yes`가 있어야 적용된다.
- discarded 후보만 retention 이후 cleanup 대상이며 pending 후보는 자동 삭제하지 않는다.
- `POLICY.json`에 review retention 설정을 추가한다.
- cleanup과 purge를 문서상 분리한다. purge는 후속 범위다.

## v0.26

- command catalog는 영어 canonical metadata를 source of truth로 유지한다.
- 한국어 trigger를 language pack으로 분리한다.
- built-in pack과 user override 구조를 구분한다.
- `cosia command triggers check`와 `cosia command triggers sync --locale ko`를 추가한다.
- trigger pack check는 짧은 trigger, mutation/dangerous trigger 위험, duplicate trigger를 진단한다.
- provider 기반 trigger 자동 번역은 후속으로 둔다.
- TUI 도입 여부는 status/start/chat/Telegram 사용 병목을 보고 결정한다.

## Test Plan

- Telegram `/review` compact output, callback query, preview-only mutation, stale preview rejection.
- Gateway heartbeat, stale lock detection, `unlock --stale-only`, log/state/status 기록.
- Review stats와 discarded cleanup preview/apply. Pending 자동 삭제 금지.
- Korean language pack check/sync, trigger warnings, existing hash/slash/chat behavior 유지.
