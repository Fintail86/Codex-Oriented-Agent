# COSIA v0.6.1 + v0.7 Plan: Prompt Polish and Controlled Tools

## Summary

Polish v0.6 prompt/context usability, then add readonly Git/NPM tools under Policy Core.

Versions:

- `0.6.1`: prompt/context polish.
- `0.7.0`: controlled capability tools.

## v0.6.1 Key Changes

### Prompt Manifest Summary

Add:

```text
cosia session prompt <session-id> --latest
cosia session prompt <session-id> --limit <n>
```

Output:

- runId
- modelStep
- promptChars
- estimatedTokens
- overflowed
- block original/retained chars
- truncated flag

Do not output raw prompt text.

### Context Undo

Add:

```text
cosia session context undo-last <session-id> --reason "<reason>"
```

Behavior:

- Move the last `## Run ...` entry from `CONTEXT_MEMORY.md` to `CONTEXT_ARCHIVE.md`.
- Do not erase without trace.
- Archive includes `movedAt`, reason, and original entry.
- Preserve `CONTEXT_MEMORY.md` header.
- Empty context produces a friendly no-op message.

`init` and `session create` create `CONTEXT_ARCHIVE.md`.

## v0.7 Key Changes

Add readonly tools:

```text
git_status
git_diff
git_log
npm_test
npm_typecheck
```

Rules:

- Permission: `read_only`.
- No generic shell.
- Each capability is a dedicated `ToolDefinition`.
- Tools run through Tool Registry and Policy Engine.
- Add tools to architect manifest repair and default policy.
- `requireTools.observationTools` remains only `read_file`, `search_files`.

Tool behavior:

- `git_status`: `git status --short --branch`.
- `git_diff`: `{ path?: string, staged?: boolean }`, workspace path only, path traversal protected.
- `git_log`: `{ maxCount?: number }`, default 20, max 50.
- `npm_test`: run fixed `npm test` only if script exists.
- `npm_typecheck`: run fixed `npm run typecheck` only if script exists.

Output limits:

- `git_diff` and npm output capped at 12000 chars.
- Use head+tail truncation.
- Always preserve truncation marker:

```text
[COSIA: tool output truncated, originalChars=..., retainedChars=..., omittedChars=.... Do not infer that omitted output was inspected or problem-free.]
```

CLI exposure:

```text
cosia tool git-status
cosia tool git-diff [--path <path>] [--staged]
cosia tool git-log [--max-count <n>]
cosia tool npm-test
cosia tool npm-typecheck
```

## Test Plan

v0.6.1:

- `session prompt --latest` and `--limit` summarize prompt manifests.
- Prompt body is not printed.
- `context undo-last` archives last run entry.
- Empty context undo is safe.

v0.7:

- Tool names are valid in schema, registry, and policy.
- Architect manifest allows readonly tools.
- Git tools audit decisions.
- `git_diff --path` rejects outside-workspace paths.
- `git_log` max count is enforced.
- NPM tools run only package scripts.
- Long output includes truncation marker.
- Shell permission remains disabled.
- Mock provider covers tool-call flow.

## Assumptions

- No git commit/push tools.
- No generic shell.
- JSONL-to-SQLite queue migration remains v0.8.
