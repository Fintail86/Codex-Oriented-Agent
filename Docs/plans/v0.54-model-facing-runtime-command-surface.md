# COSIA v0.54 Plan: Model-Facing Runtime Command Surface

## Summary

v0.54의 목표는 LLM이 COSIA CLI를 안전하게 참고하고 사용할 수 있도록, COSIA CLI 전체 명령어와 1:1 매칭되는 Command Catalog를 만들고, 사용자 입력에서 감지된 tag word를 기준으로 관련 command list를 LLM에게 제공하는 것이다.

## Key Changes

- 버전은 `0.54.0`.
- 상태별 hardcoded inspector tool은 만들지 않는다.
- 자연어 command translator는 만들지 않는다.
- CLI 문자열 실행은 금지한다.
- LLM은 runtime이 제공한 후보 리스트에서 `commandId`를 선택한다.
- runtime은 `commandId -> fixed CLI argv plan`으로 변환해 COSIA CLI를 `execFile/spawn` 방식으로 실행한다.
- catalog entry가 있다고 해서 실행 가능한 것은 아니다.
- `safety`, Gateway role, approval gate, policy gate가 실행 여부를 제어한다.

## Public Model Tools

```ts
cosia_cli_command_lookup({
  input: string,
  commandId?: string,
  safety?: string,
  limit?: number
})

cosia_runtime_command({
  commandId: string,
  args?: Record<string, unknown>
})
```

## Safety

- shell string execution is forbidden.
- unknown args and secret-like dynamic args are rejected.
- read-only modelCallable command may execute.
- mutation/system-boundary/dangerous commands are cataloged but blocked for normal model-facing execution.
- private master direct Telegram chat may execute normal non-system CLI mutations through commandId, while system-boundary/dangerous/shell/pending apply remain blocked.

## Test Plan

- catalog covers representative CLI commands with stable `commandId`.
- lookup detects tag words without phrase-specific hardcoded mapping.
- runtime command rejects CLI strings.
- `memory.search` uses the real `--query` CLI option shape.
- gateway admin can execute read-only commands only.
- private master direct chat can execute allowed normal mutation commandIds.
- outputs are sanitized/truncated.

## Assumptions

- command catalog metadata is safety boundary metadata, not a natural-language command translator.
