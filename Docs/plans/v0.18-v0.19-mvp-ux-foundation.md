# COSIA MVP UX Foundation Phase

## Summary

- `v0.18`: promote `cosia status` into a user-facing home screen and add `cosia doctor` diagnosis, repair, and safe reset.
- `v0.19`: add `cosia start` as the guided session/provider/agent entrypoint.
- Do not add `cosia workspace`.
- Do not auto-create sessions from `agent create`; `start` handles session creation/selection.
- Keep TUI as a v0.20 decision checkpoint after using `status + doctor + start + chat`.

## v0.18

- Add status issues with `critical | warning | info` severity and sorted recommended actions.
- Add `status --compact` and `status --json`.
- Add `doctor`, `doctor repair`, `doctor reset --state`, and `doctor reset --factory`.
- `doctor repair` must be deterministic and idempotent.
- reset uses `copy -> verify -> delete original`, stores backups under `.cosia-reset-backups/<reset-id>/`, and writes `recovery_manifest.json` on failure.
- reset never touches source code, package files, README, or git history.

## v0.19

- Add `cosia start`.
- Interactive session selection uses number input only; no external UI dependency.
- Empty input selects the recommended session.
- Recommended session is active, non-orphan, latest `updatedAt`, then session id ascending.
- `--no-chat` prints the selected next command without entering chat.

## Validation

- `npm run typecheck`
- `npm test`
- `npm run build`
- `cosia policy check --repair`
