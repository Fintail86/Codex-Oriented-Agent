# COSIA v0.11 Plan: Agent Identity, Default Agent, and Guided Bootstrap

## Summary

Make agents replaceable identity/work-style units and add default-agent management plus guided recovery when no usable agent exists.

Version: `0.11.0`.

## Key Changes

### Agent Identity

Extend manifest:

```ts
type AgentIdentity = {
  role: string;
  voice: string;
  operatingStyle: string[];
  priorities: string[];
  boundaries: string[];
};

type AgentManifest = {
  identity: AgentIdentity;
  selectionTriggers: string[];
  preferredSkills: string[];
  blockedSkills: string[];
  skillWeights?: Record<string, number>;
};
```

Rules:

- `manifest.json` is identity source of truth.
- `AGENT.md`, `STYLE.md`, and `LOCAL_RULES.md` remain supplementary prompt/human docs.
- Existing agents are repaired on load.
- PromptBuilder must include:
  - `AGENT IDENTITY (JSON)`
  - `AGENT SUPPLEMENTARY PROFILE`
  - `AGENT STYLE`
  - `AGENT LOCAL RULES`
- `STYLE.md` remains included.
- Agent identity/profile/style/rules are not truncated by prompt budget.

### Default Agent

Policy:

```json
{
  "agents": {
    "defaultAgentId": "cosia-agent"
  }
}
```

Commands:

```text
cosia agent default show
cosia agent default set <agent-id>
```

Rules:

- Fresh `init` creates `cosia-agent` and sets it default.
- Existing workspace with valid default is not forced to create `cosia-agent`.
- `session create --agent` becomes optional.
- Without `--agent`, use current default agent.

### Guided Bootstrap

Add:

```text
cosia agent bootstrap
cosia agent bootstrap --id <agent-id> --name "<name>" --role "<role>" --voice "<voice>"
```

Behavior:

- Interactive wizard by default.
- Non-interactive flags supported.
- Creates agent and sets it as default.
- No LLM call.
- Missing/default-broken agent state shows bootstrap hint.

### Agent Create/Delete

Commands:

```text
cosia agent create <agent-id> --template cosia
cosia agent create <agent-id> --template architect
cosia agent list
cosia agent show <agent-id>
cosia agent delete <agent-id>
cosia agent delete <agent-id> --yes
cosia agent delete <agent-id> --yes --force
cosia agent delete <agent-id> --yes --force --allow-empty
```

Delete policy:

- Preview by default.
- Default agent deletion blocked by default.
- Session-referenced agent deletion blocked by default.
- `--force` permits session references.
- Last/default deletion requires `--allow-empty`.
- Only `agents/<agent-id>/` is removed.
- Sessions and memory are not touched.

### Agent Recommendation

Add:

```text
cosia agent recommend --prompt "<prompt>"
cosia agent recommend --prompt "<prompt>" --goal "<goal>" --explain
```

Rules:

- Deterministic only.
- Score from `selectionTriggers`.
- Current prompt match: +5.
- Goal match: +2.
- Tie-break: default agent first, then id alphabetically.
- Recommendation does not change sessions/run/chat automatically.

## Test Plan

- Fresh `init` creates `cosia-agent` and default policy.
- Existing default is not overwritten.
- `session create --goal` uses default.
- Missing default fails with bootstrap hint.
- Bootstrap interactive and flag-only paths create default.
- Default set rejects missing agent.
- Delete preview does not mutate.
- Default/last/session-referenced deletion guardrails work.
- PromptBuilder includes identity/profile/style/local rules.
- Style is included.
- Agent identity blocks are not truncated.
- Recommendation explain table is deterministic.
- Recommendation does not mutate sessions.
- Existing v0.10 skill tests pass.

## Assumptions

- `cosia-agent` is not immutable.
- Zero-agent workspace is allowed but guarded.
- Bootstrap is deterministic and local.
- Automatic routing is deferred.
