# COSIA v0.9 Plan: Structured Skill Candidate Loop

## Summary

Add the first concrete self-improvement loop: model-proposed skill candidates can be reviewed, promoted, and loaded into prompts.

Version: `0.9.0`.

This plan was later superseded by v0.10, which moved skills from agent-local ownership to a global toolbox.

## Key Changes

### Skill Candidate Storage

Add SQLite `skill_candidates`.

Model output gains:

```ts
skillCandidates?: Array<{
  agentId: string;
  skillName: string;
  reason: string;
  content: string;
  triggers?: string[];
  riskLevel?: "low" | "medium" | "high";
}>;
```

Candidates remain pending until explicit promotion.

### Agent-Local Skill Files

Initial canonical location:

```text
agents/<agent-id>/skills/<skill-id>.md
```

`agents/<agent-id>/SKILLS.md` is generated mirror/index.

Rules:

- Do not parse/patch arbitrary sections of `SKILLS.md`.
- `skill sync <agent-id>` regenerates mirror.
- Duplicate skill id fails.
- Triggerless skill is manual-only.

### CLI

Add:

```text
cosia skill candidate list
cosia skill candidate show <candidate-id>
cosia skill candidate promote <candidate-id>
cosia skill candidate promote <candidate-id> --yes
cosia skill candidate discard <candidate-id> --reason "<reason>"
cosia skill candidate export --jsonl
cosia skill list --agent <agent-id>
cosia skill show <skill-id> --agent <agent-id>
cosia skill sync <agent-id>
```

Promotion:

- Default is preview only.
- `--yes` mutates files.
- Triggerless preview warns manual-only.
- Secret-like content is high-risk and redacted.

### PromptBuilder Skill Loading

- Read skill body from skill files, not from `SKILLS.md`.
- Select by triggers matched against session goal and current request.
- Manual selection:

```text
cosia run --session <id> --prompt "..." --skill <skill-id>
cosia chat --session <id> --skill <skill-id>
```

Chat commands:

```text
/skills list
/skills use <skill-id>
/skills drop <skill-id>
/skills clear
```

Wrap skills with XML-style boundaries.

### Trigger Scoring

Rules:

- current request exact phrase: +5
- session goal exact phrase: +2
- ASCII/code-like triggers use word-boundary matching.
- Korean/phrase triggers use normalized phrase matching.
- 1-2 character triggers are excluded from automatic matching.
- Repeated trigger counts once.

### Skill Budgeting

Defaults:

```json
{
  "skillMaxItems": 5,
  "skillMaxChars": 8000,
  "skillItemMaxChars": 2000
}
```

Selected skill information is recorded in `PROMPT_MANIFEST.jsonl`.

## Test Plan

- Skill candidates store as pending.
- Candidate list/show/export works.
- Preview promote does not mutate.
- Promote writes skill file and mirror.
- Triggerless skill warns manual-only.
- Duplicate skill id fails.
- PromptBuilder loads trigger-matched skills.
- Manual skill selection works.
- XML-like content cannot break boundaries.
- Skill budget omits/truncates low-priority skills.
- Secret-like skill is high-risk/redacted.

## Assumptions

- Skill self-improvement starts agent-local.
- Automatic skill promote is not allowed.
- Codex law is not modified in v0.9.
