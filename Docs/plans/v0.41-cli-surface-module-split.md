# COSIA v0.41 Plan: CLI Surface And Module Split

## Summary

v0.41의 목표는 기능 변경 없이 `src/cli.ts`를 top-level command assembler로 줄이고, 명령 그룹을 `src/cli_commands/` 모듈로 분리하는 것이다.

## Key Changes

- 버전은 `0.41.0`.
- shared CLI helper를 `src/cli_commands/shared.ts`로 분리한다.
- gateway/Telegram, config/policy, capability/shell, tool/tool-growth, memory/skill/review, agent/session/start/run/chat 명령을 그룹 모듈로 분리한다.
- `src/cli.ts`는 program 생성, deps 구성, register 호출, parse/error handling만 담당한다.

## Guardrails

- 명령 이름, 옵션 이름, 기본값, 에러 조건, 출력 구조를 바꾸지 않는다.
- deprecated alias는 제거하지 않는다.
- provider onboarding, OAuth, connector semantics는 바꾸지 않는다.
- command_adapter, shell approval, tool growth, memory promotion 동작을 바꾸지 않는다.

## Test Plan

- `npm run typecheck`
- `npm test`
- `npm run build`
- CLI smoke: `--help`, `provider profile list`, `gateway telegram list`, `gateway status`, `config check`, `policy check`, `memory candidate list`, `session list`, `status --compact`

## Assumptions

- v0.41은 구조 리팩터이며 UX 개편 단계가 아니다.
- provider onboarding은 v0.42 범위다.
