# COSIA v0.42 Plan: Provider Onboarding And OAuth Boundary

## Summary

v0.42의 목표는 provider 설정을 사용자가 외워서 `profile add` 하는 구조에서, 지원 provider 목록과 guided/scriptable onboarding을 모두 제공하는 구조로 정리하는 것이다.

## Key Changes

- 버전은 `0.42.0`.
- provider onboarding registry를 추가한다.
- supported providers: `codex-cli`, `openrouter`, `openai-compatible`.
- guided setup CLI를 추가한다.
- 기존 `provider profile add/use/list/show/check/remove`는 유지한다.
- direct profile add도 provider descriptor validation을 통과해야 한다.
- COSIA-owned OAuth boundary를 정의하되, 공식 endpoint/refresh/token 사양 전까지 live Codex browser OAuth flow는 열지 않는다.

## Public Interfaces

```powershell
cosia provider list-supported
cosia provider setup
cosia provider setup --provider <provider-id> --name <profile-name>
cosia provider setup --provider <provider-id> --name <profile-name> --use
```

## Test Plan

- `provider list-supported` lists providers without default marker.
- guided API key setup stores secret only in private secret store.
- guided env auth stores only env var name.
- guided setup without `--use` does not select active profile.
- invalid provider/auth combinations fail with clear hints.
- `codex-cli --oauth` remains compatibility path.

## Assumptions

- Actual COSIA-owned OAuth live flow needs official provider docs before enabling.
- No provider becomes default.
