# COSIA v0.7.1 + v0.8 Plan: Search Stability and SQLite Queues

## Summary

Patch `search_files` stability, then move memory candidate/promotion queues from JSONL to SQLite.

Versions:

- `0.7.1`: search stability patch.
- `0.8.0`: SQLite queues and context size warnings.

## v0.7.1 Key Changes

`search_files` behavior:

- Prefer `rg`.
- Use Node fallback when:
  - `rg` content search fails.
  - `rg` content search is empty.
  - `rg --files` path search fails or is empty.

Fallback rules:

- Workspace inside only.
- Exclude heavy directories:
  - `.git`
  - `node_modules`
  - `dist`
  - `coverage`
  - `.next`
  - `.turbo`
- Swallow per-file/per-directory errors like `EACCES`.
- Do not follow symlink directories.
- Hard limits:
  - max files: 1000
  - max matches: 80
  - max time: 5000ms
- Add marker if stopped early:

```text
[COSIA: search fallback stopped early, reason=...]
```

## v0.8 Key Changes

Move queues into `memory/longterm.sqlite`.

New tables:

```text
memory_candidates
auto_promotions
queue_migrations
```

Migration:

- Automatic one-time import when candidate/promotion queues are first used.
- Import existing JSONL into SQLite.
- On success, move JSONL to `.bak`.
- Runtime source of truth becomes SQLite only.
- Idempotent migration with transaction and unique ids.
- Legacy id-less candidate lines are skipped and reported.

Report:

```text
memory/queue_migration_report.json
```

Add exports:

```text
cosia memory candidate export --jsonl
cosia memory promotion export --jsonl
```

### Context Size Warning

No automatic summary/archive in v0.8.

Add warning thresholds:

```json
{
  "contextWarningChars": 30000,
  "contextCriticalChars": 60000
}
```

Show context status in:

- `cosia status`
- `cosia session show`
- `cosia chat /status`

Critical hint:

```text
cosia session prompt <session-id> --latest
cosia session summarize <session-id> --content "<summary>"
cosia session context undo-last <session-id> --reason "<reason>"
```

## Test Plan

v0.7.1:

- `rg` normal/failure/empty results all work.
- Fallback finds content and path matches.
- Fallback survives unreadable paths and symlink dirs.
- Limits produce marker.

v0.8:

- JSONL queues import once.
- JSONL files move to `.bak`.
- Re-run does not duplicate records.
- Mid-failure recovery avoids duplicate insert.
- Legacy lines are reported and skipped.
- Candidate promote/discard/review still works.
- Auto-promotion and revert still work.
- Export produces JSONL-compatible output.
- Context warnings appear.

## Assumptions

- Queue migration is one-way.
- `.bak` files are preservation only.
- Session auto-summary remains deferred.
