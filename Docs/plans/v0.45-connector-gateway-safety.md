# COSIA v0.45 Plan: Connector / Gateway Safety

## Summary

v0.45의 목표는 Telegram과 future connector를 COSIA의 external body로 안전하게 정리하는 것이다.

## Key Changes

- 버전은 `0.45.0`.
- provider 선택은 provider profile이 소유한다.
- Telegram은 connector 설정만 소유한다.
- group chat은 기본 read-only다.
- group mutation은 chat allowlist만으로 허용하지 않고 user-level authorization을 요구한다.
- `/whoami`로 chat id, user id, chat type을 확인한다.
- Telegram `getUpdates`에 `allowed_updates: ["message", "callback_query"]`를 명시한다.
- unknown/group block response throttle을 in-memory TTL로 둔다.

## Public Interfaces

```text
cosia gateway telegram set user-id <user-id>
cosia gateway telegram unset user-id <user-id>
cosia gateway telegram set mutation-user-id <user-id>
cosia gateway telegram unset mutation-user-id <user-id>
cosia gateway telegram set group-mode read-only
cosia gateway telegram set group-mode allowed-users
```

## Test Plan

- legacy config without group fields migrates through defaults.
- private chat compatibility remains.
- group read-only mode allows `/whoami`, `/help`, `/status`.
- group mutation requires allowed chat, allowed user, mutation user, and `allowMutations=true`.
- unknown users are blocked before provider calls.

## Assumptions

- Telegram remains the only implemented connector.
- group read-only default is intentional.
